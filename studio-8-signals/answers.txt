A server program could handle SIGTERM (or SIGHUP) so that when the OS or an admin asks it to shut down, it can finish in-flight requests, flush buffers, close files and sockets, and clean up before exiting instead of being killed abruptly. Another example is SIGALRM, used to handle timers and timeouts asynchronously.
